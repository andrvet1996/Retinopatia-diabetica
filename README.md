Análise de Imagens de Retina com BRSET

Este projeto é uma análise de imagens de retina usando o Brazilian Multilabel Ophthalmological Dataset (BRSET).

A ideia é trabalhar com os dados disponíveis no dataset e desenvolver a análise desde a primeira etapa, explorando as imagens, os dados clínicos e as informações disponíveis para entender melhor o conjunto de dados.

Ao longo do projeto, serão realizadas análises das imagens e dos dados, além de testes com técnicas de Machine Learning e Visão Computacional aplicadas à área de oftalmologia.

Sobre o dataset

O BRSET reúne imagens de fundo de olho de pacientes brasileiros, junto com informações clínicas e classificações relacionadas às imagens.

O dataset utilizado neste projeto está disponível no PhysioNet:

https://physionet.org/content/brazilian-ophthalmological/1.0.2/

Análise

A análise começa pela exploração dos dados e das imagens, passando pelo tratamento e organização das informações. A partir disso, serão realizados experimentos para encontrar padrões e avaliar diferentes abordagens.

Os resultados e aprendizados obtidos durante o desenvolvimento serão registrados neste repositório.
